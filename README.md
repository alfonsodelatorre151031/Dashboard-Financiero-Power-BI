# Dashboard-Financiero-Power-BI
Dashboard interactivo desarrollado para analizar ingresos, pagos, impuestos y utilidad. Este Dashboard fue elaborado para propósitos académicos.

##  Objetivo

Analizar el comportamiento de los movimientos financieros y facilitar la identificación de variaciones mensuales, resultados de utilidad y distribución de transacciones por institución bancaria.

##  Herramientas

- Power BI
- Power Query
- DAX
- Data Visualization

##  Principales KPIs

- Pagos recibidos: $24.1 M
- Pagos realizados: $20.4 M
- Impuestos: $3.86 M
- Utilidad: -$95.7 K
- Número de movimientos: 703

- ## Principales hallazgos

- La utilidad acumulada presenta un resultado ligeramente negativo.
- Junio presenta una de las mayores disminuciones de utilidad.
- Bank of America concentra la mayor cantidad de pagos recibidos.
- 29.59% de las transacciones fueron realizadas con tarjeta.
